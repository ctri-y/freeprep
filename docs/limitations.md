# 当前边界

- **教学验证范围：** 已在初高中物理中多轮迭代。通用学科流程尚需数学、语言及人文学科的真实试用；结构通用不等于所有学科效果已经验证。
- **来源核验：** 由执行 skill 的助手实际检索和阅读。脚本检查记录是否齐全、是否标记已读，无法证明记录真实、页面仍可访问或材料允许公开。
- **答案：** 附带的示例有独立数值复算，但脚本不通解任意题目。教师必须复核。
- **练习比例：** 配置的是备课原则。页数、题数和材料齐全不能保证课堂实际练习时间达到某比例。
- **学生打印：** 通过「打印练习」生成仅题干、题设图与作答区的题单。授课 HTML 本身包含教师答案，不适合作为保密考试系统。教师解析页不进入该题单。
- **批注：** 保存在浏览器本地，不会同步账号。隐私模式、浏览器清理与 `file://` 的存储策略可能影响保存；重要批注请导出。不同版本题义变化时需更换页面 ID。
- **输出：** 当前公开模板直接生成单文件 HTML、分镜 JSON、来源台账和教师 Markdown 解析。PDF 需浏览器打印；PPTX/Keynote 需要助手额外调用对应工具。多课程导航门户尚未打包。
- **图示与数学：** 当前模板的基础类型见数据说明。复杂装置图、电路、化学结构或高级公式需要按学科扩展并核验。无法识别的图示会报错，避免悄悄显示错误替代图。
- **可及性：** 提供键盘、焦点样式、图像替代文本与减少动态效果支持；还未完成全面辅助技术审查。

后续优先验证跨学科真实案例、扩展复杂公式与学科图示、提炼多课程门户。新增能力应附最小复现课程和实际渲染检查。
