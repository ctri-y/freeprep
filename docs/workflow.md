# 从教材到课堂

FreePrep 是给 AI 助手执行的工作流，不是一个独立爬虫或固定题库。教师仍然决定目标、范围与教学节奏。

## 需求与课程依据

优先从已有对话提取参数，避免重复采访。读取实际教材的封面、版权信息、目录与指定章节；再找当前适用的官方课程或考试要求。教材正文、官方要求和题库资料分别记录。无法读取正文的链接只能作为候选。

更换教材、年级或地区时重新映射章节，不继承上一次的题源地区和章号。没有传统考纲时，以现行官方要求为准，不虚构未来考试比例。

## 内容与选题

围绕概念的解释关系组织模块，保留定义、使用条件、必要推导和反例。按学生基础增加前置知识、提示和梯度，而不是直接删掉原理。

题目先找来源再确认题干，记录是原题、改编还是原创。每题保留目标、难度、稳定 ID、完整题干、图示、答案、推理与出处。难题应检验关键理解，避免堆未教过的知识。计算题独立复算，并提供完整图解、已知、所求、列式、代入、单位与结果核对。

## 分镜与成品

每页十项分镜在课程 JSON 中保存。用户要求先审批时先交分镜；已经明确授权按确认标准继续整章交付时，直接完成并附分镜。

HTML 只是当前附带的可运行输出引擎。其他格式可以按用户工具环境生成，但不能把单张整页图片包装成“可编辑课件”。

## 交付检查

检查范围、来源、答案、图文一致、单位、坐标轴、标签、学生版隐藏答案、打印分页、批注及离线导航。自动脚本输出 `structure_valid`，始终同时标记需要人工内容复核。教师实际试用后的反馈用于调整下一版 skill 和材料。

多学段入口按「高中 / 初中 → 年级与学科 → 章节」组织。当前发布包只有单课程演示，尚未把私人多课程门户抽象为通用生成器。
