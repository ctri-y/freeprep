# 来源与题库

## 来源台账

每个来源记录：稳定 `id`、标题、机构、URL、发布时间或版次、查阅日期、来源类型、访问状态、核验范围、页码/题号和备注。对于下载文件，另记本地路径、页数及文件名与实际封面的对应关系。

建议类型：`official-primary`、`official-reprint`、`publisher`、`third-party`。建议状态：`read`、`candidate`、`restricted`、`failed`。

原发布网站不可用时，可以采用明确标注出处的官方转载并说明；查不到原件和法规未来适用时间时不要补造网址或结论。访问受限、付费、登录页不是已读材料。

发布年、考试年、上传年和再版年各有不同含义，尤其注意旧教材“必修1”与新教材“必修第一册”、不同地区“学考”与“选考”的区别。

## 题目条目

题库 JSON 为数组，每题含：

```json
{
  "id": "Q01",
  "module": "M01",
  "target": "要检查的理解或技能",
  "difficulty": "基础",
  "question": "学生看到的完整题干",
  "answer": "教师答案",
  "reasoning": "可核查的解释或计算",
  "hints": ["需要时才给出的提示"],
  "source_kind": "original",
  "source_id": null,
  "locator": null,
  "adaptation": null
}
```

`source_kind` 取 `original`、`adapted`、`verbatim`。原题与改编题填写来源 ID 和原题定位。改编题另写改变的条件/数值，并重新解答。原题索引另表保存，不能以索引替代题干。

用户要求出处显示在每题末尾时，补充 `citation_label`，并记录 `source_year`、`source_place`、`year_kind` 与 `evidence_level`。考试年、情境发生年、上传年和教辅版次不能混用。教辅没有标原考试出处的题，显示教辅学年/版次、书名、出版社及页码题号，不捏造地区考试身份。教辅标注的考试题但尚未核到原卷时，显示“据某教辅转录”，不宣称已核对官方原卷。

原创上限读取当前项目的 `max_original_questions`，不是整个 skill 的统一常数。原创仅用于用户允许且来源题不能满足的任务；用户要求新颖时，优先设计证据冲突、数据可信度或跨表征推理等实质任务，不以换名、换数包装基础套公式题。没有必要就不使用原创额度。新增独立作答追问同样计入原创约束。

先筛选来源题再配图。原题已有图时检查实际原图；重绘保持题设数据、方向与结构，补充教学图另记用途。来源身份不明、题图缺失、条件有误或超出当前章节的题不能进入正式候选题库。

## 合理使用

优先链接公开原卷、出版方样书和可核验资源。按使用权限决定是否下载、摘录或分发。引用少量短内容，避免复制整本教辅或大段教材到交付材料；题目与知识解释可用原创表达和明确标注的改编。分享 skill 时保留来源检索方法和链接，不附带第三方教材/题库全集。

图片题若缺图就不算完整题。重绘实际证据图时核对坐标、标尺、方向和条件；不要把模糊截图当作已经校验的图像题。

## 题目梯度与完整讲评

难度按实际推理任务判断，不只换标签或增加数字复杂度。基础题建立定义，中档题练单个方法，提高题可组合条件辨析、反向求解、实验约束或图文转换。提高题放在必要概念学完之后，穿插在能巩固相关认识的基础/应用题之间；不能为了难度引入当前范围以外的公式。目录和打印题单保持同样教学顺序。

有必要的计算或定量图像题，给独立完整讲评：保留原题、已知/所求、与条件一致的图、关系式选择、单位换算、逐项代入、结果与边界检查。相同方法可以解释一次，但各所求量的必要代入不能只报结果。非计算题的解析说明“条件→依据→结论”，并解释关键错误选项或反例。

修改后重算当前题干，不继续沿用源选择题的旧选项字母或不同数据。保留稳定题号；新增题和答案页使用新ID，避免把旧题笔迹错配到新题。打印排除答案页，题页先给题设图，讲评再给辅助线和所求结果。
