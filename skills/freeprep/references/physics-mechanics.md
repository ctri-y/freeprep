# 力、平衡与牛顿运动定律

用于受力分析、力合成分解、接触与约束、牛顿运动定律及超重失重。按本次实际教材安排深度，不强加特定年级题库。

- 每个真实力能指出施力者与受力者；平衡力属于同一对象，相互作用力分属两对象。合力、分量和ma不额外画成独立真实力。
- 静摩擦先由状态求所需值，再查上限；动摩擦系数不能独自确定起动阈值，题设需补条件时记录改编，不替原题暗设相等。
- 支持力由法向方程决定，不自动等于mg。斜拉、水平推斜面、竖直加速等情境保留其他力的法向分量。
- 绳只拉、接触只推；整体法求共同加速度后仍隔离求内力，检查T、N非负。负支持力表示接触假设失效，随后重新分段。
- 速度通常连续，加速度可随力变化突变。理想弹簧剪断上方绳的瞬间长度来不及改变，弹力保留；已解除绳约束的张力可立即归零。
- 只有合力或加速度大小时，保留方向分支；反正切结果结合分量象限，不能漏掉另一组解或把钝角写成锐角。
- 超重失重按竖直加速度判断；完全失重仍有重力。若下方接触模型算出负支持力，应改查脱离，而不是继续报负秤读数。
- 相对运动题分别画对象的地面位移或速度，再取差；划痕不等于其中一个对象的路程。
- 实验区分所测拉力和系统合力；钩码重力近似拉力有质量比条件。用已经学过的定律反查实验近似，不把它当作证明自身的实验结论。
- 图解同时核对几何与受力：绳力沿绳、支持力沿法线、摩擦沿切线。移动物体速度箭头顺着实际方向；悬挂静止物体的重心在悬点竖直下方。
