# 需求与交付

## 最小参数

从上下文优先取得：科目和学段，地区/课程体系，教材与版本，完整范围，教学模式，学习基础与目标，教学方法，课时约束，讲练原则，交付格式，视觉风格，排除项。

缺失信息分两类：必须知道的范围/教材/核心目标，以及可以公开采用默认值的排版或文件命名等。不要用可合理决定的实现细节持续采访用户。

## 模式

- 首次教学：概念形成、示例、独立练习、纠错、迁移。
- 预习：前置知识、自主阅读线索、少量自检；用户没有要求时不附加。
- 复习：知识关联、诊断题、薄弱点练习、综合迁移。
- 错题讲评：保留原题，辨认错因，给出修复练习。

## 交付约定

按用户要求选择：可编辑课件、学生练习、教师解析、课后巩固、参考来源。打印版与可编辑版可同时交付，但不自行增加预习、考试卷或学习计划。

用户说“整章全部出完，自己决定每次讲多少”时，输出完整章节目录和模块入口，省略每次授课内容安排、模块分钟数与总课时估计。不要把“先做一节样课”当作本批终点。

视觉风格选择不代表教学方法选择。三种不同视觉风格应沿用同一题干、数值和知识目标。

项目参数 JSON 示例字段：`subject`、`region`、`grade`、`textbook`、`scope`、`mode`、`pacing`、`practice_share_min`、`deliverables`、`excluded_deliverables`、`style_status`。参数只保存本项目的选择，不设为所有学科的强制默认值。
