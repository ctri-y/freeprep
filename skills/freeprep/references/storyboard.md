# 教学与视觉分镜

先读教学正文、题库和适用课程范围，再规划页面。分镜是可审阅的教学方案，不能只把标题分成幻灯片页。

每页保存标题、编号、内容类型和以下十项；用户指定英文键名时保持对应关系：

1. **Teaching objective**：学生能做出的具体判断、解释或操作。
2. **Core concept**：本页要建立的认识，必要条件与易混点。
3. **Required equations**：所需公式、推导中间式与单位。没有公式的学科/页面明确写无，并指出所需文本证据。
4. **Required diagram / graph**：支持理解的图、记录表、史料或文本证据。注明已有资产、准确题图的来源定位、数据及作图空轴，不用“放一张图片”替代需求。
5. **Logical sequence**：实际课堂的思考顺序，说明问题怎样导向定义、解释、计算或检验。
6. **Recommended slide archetype**：依据内容选择情境对照、图文解释、分步推导、数据到图像、图像读数、题目与作答区等版式。避免整章只有一种套版。
7. **Visual hierarchy**：明确最先注意的对象、第二层条件/证据、辅助说明与出处的层级。
8. **What should appear immediately**：首屏完整给出学生独立任务所需的信息，尤其完整题干、已知条件、题图与题尾来源。
9. **What should be progressively revealed**：教师触发的观察标记、推导步骤、条件检查和答案。逐步揭示服务思考，不按秒自动播放，不在学生尝试前给答案。
10. **Final takeaway**：完成本页后学生应记住的一个结论，包含必要适用条件。

练习页另关联稳定题号、完整题干/已核读原题、题尾出处和教师解析。分镜审阅阶段可以展示短题意与原题定位，必须明确这不是最终题单；制作阶段不能只用摘要替代完整题干。按知识模块备齐整个请求范围，不擅自分课时或用页面数量宣称达到实际练习时间占比。

用户明确要求批准分镜后再做课件时，保存 `storyboard_status=awaiting-user-approval`。本轮交付分镜和题源清单，停止课件生成。只有用户明确批准该分镜或明确取消这一步，才进入可编辑PPTX/Keynote制作。旧版风格认可不代表新分镜已批准。

记录批准后的页面内容与揭示顺序。平台暂不支持编辑动画时，依照批准的逻辑制作逐步页面或讲者提示，不能在分镜阶段冒称已具备可编辑动画。
