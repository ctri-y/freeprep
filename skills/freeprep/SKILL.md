# FreePrep · 只管教

把教师的教学意图转化为可直接使用、可修改、有来源记录的材料。科目、地区、教材、学生基础和输出形式都是项目参数；不要把一个教师的偏好固定为所有用户的规则。

## 确定当前任务

先从已有对话和文件中提取要求，只询问会改变成果的缺失信息。用户已经回答的事项不要重复询问。细化参数时读 [需求与交付](references/intake-and-delivery.md)。

- 区分首次教学、预习、复习、错题讲评和专项训练。仅生成用户需要的模式。
- 确认完整范围：一小节、一大章、某个考点或指定清单。
- 分开记录教学方法与视觉风格。学生基础影响题目梯度、提示和前置知识，不必降低原理解释的深度。
- 先检查教师是否要求固定课时。用户要求整章备齐、自定节奏时，用知识模块组织，省略模块时长和分课时计划。
- 区分硬约束、已确认偏好、建议、待选项。新明确要求覆盖旧建议，随即更新项目记录。

## 核对课程依据

以指定教材组织内容，以当前适用的官方课程/考试要求确定学习目标。读 [来源与题库](references/sources-and-exercises.md)。

- 找到出版社、官方教育平台或正规馆藏入口，核对封面、出版信息和目录。相似标题和上传者标签不能证明教材版本。
- 检索发布机关的现行要求，记录发布日期、修订版、查阅日期和适用对象。不要假定某地区仍有传统“考试大纲”。
- 区分官方原件、官方转载、出版方资料与第三方材料。不能读取正文时标为候选，不把搜索摘要算成已核验正文。
- 官方主题常覆盖多个教材章节；把要求映射到当前范围，不因此扩展用户指定的章节。
- 地方未来考试的规则尚未发布时，说明采用目前有效要求，避免推断未来分值、题型或必考比例。

## 设计概念与任务

从学科内部的解释关系组织材料。让学生看见概念/方法解决的具体问题、证据或定义依据、使用条件和边界，再用于新情境。适当加入反例，定位常见混淆。

物理任务读 [物理材料](references/physics.md)。涉及力、平衡、接触约束、牛顿运动定律与超重失重时，补读 [力学材料](references/physics-mechanics.md)。其他学科按本学科的证据标准组织：数学区分定义与证明，语言学科区分文本证据与解释，历史区分史料与推断等。不要把物理公式推导套路套用到所有学科。

一个知识模块可包含：引入问题、核心解释、必要图示/证据、教师示例、学生独立任务、纠错和迁移。按实际内容调整，不为凑模板增加空页。

用户要求练习至少占一半时，提供充分且分层的学生任务。教师演示、提示讲解和答案讲评属于讲授。若教师自行安排课时，只保留比例原则，不虚报材料能自动保证实际用时。

## 准备练习和解析

- 优先从已读教材、教辅、考试原卷或可核验转录中选题。先记录用户允许的原创数量上限、原创用途及题尾出处格式。不能把自己写的普通题补挂到相似题源下，或把改编、追问拆成多题以绕过数量约束。
- 每题明确目标、前置知识、题型、难度及稳定编号。
- 记录题目属于原题、改编还是原创。改编说明改动，并保留源题定位；原创题不挂名真实试卷。
- 原题身份用原卷或发布机构交叉核对。自行解答与官方答案分开标注。
- 数值题独立重算，检查单位、方向、条件与唯一性；开放题给出证据要求和可接受的解释范围。
- 题干与解析分别交付，学生版本保留作答空间，避免泄漏答案。
- 原题索引可以补充题库，不能将一堆待登录链接称为完整课堂练习。

## 制作与核验

先把整个请求范围的内容和练习准备到可审阅状态，再处理尚未决定的视觉选项。

用户要求分镜先行时，读取教学内容后，先完成逐页教学与视觉分镜，读 [分镜与呈现](references/storyboard.md)。每页明确目标、核心概念、公式/证据、必要图示、逻辑顺序、版式原型、视觉层级、首屏、逐步呈现与最后带走的认识。完整范围与题源准备好后交给用户审阅；用户批准分镜以前不生成PPTX、Keynote或最终幻灯片渲染。不要用旧的风格认可代替新的分镜批准。若用户明确授权按已确认标准直接完成后续成品，则按该授权制作，并随成品保留完整分镜，不自动重新要求逐轮批准。

需要用户选风格时，提供相同教学内容的风格预览，方便比较。用户指定预览数量、图片生成方式或模板时遵从；如具体模型不能指定，说明实际工具，避免冒称使用了指定模型。可在选风格期间继续准备内容和打印材料；最终课件按用户选定风格制作。

交付 PPT 时保留可编辑题干、公式、表格及教学图示。图片生成适合情境插画、装饰或风格预览；数学与科学证据图示还须独立检查。优先使用当前环境已有的文档/演示文稿工具，条件不足时报告具体限制，不把 PNG 整页贴入 PPT 当作可编辑成果。

讲解和必要练习须有帮助理解的图片或证据图，不只靠文字堆叠。选图、题设图和图文布局读 [教学配图](references/visual-materials.md)。用户已经认可风格时，保持该风格完成内容修订；配图与学生题单、教师解析同步，不删必要推导或泄漏作图答案。

核验内容覆盖、来源、答案和视觉可读性。渲染课件/打印材料，检查中文、公式、图轴、箭头、分页及学生答案隐藏。具体检查与迭代读 [反馈与质量](references/revision-and-quality.md)。

对于采用本 skill 的题库 JSON，可运行 `scripts/check_materials.py` 检查编号、来源定位和参数一致性；它不能验证答案真实正确或官方文件是否仍然有效。


多学段或多年级材料共用入口时，先按学段分类，再按年级与学科、具体章节逐层导航；同一课程的旧章与新章按教材顺序归并，不用交付批次作为教学主目录。检查面包屑、返回路径、离线相对链接与共用课件的章节定位。

## 迭代与分享

用户要求记录提示词时，在工作区保存其任务原文、确认要求和反馈。项目对话用于追溯；分享包提炼通用流程、必要脚本和匿名示例，不默认附带个人对话及第三方整本教材/题库。

修改已有成果时保留稳定题号和可比较版本，记录反馈、改动原因和验收状态。以实际产物测试流程，未收到用户满意反馈前保持草稿/候选版本，不宣称最终验收。

## 初中热学分支

任务涉及温度、物态变化、内能、比热容、热机或热值效率时，补读 [physics-thermal.md](references/physics-thermal.md)。地区与删减范围读取当前项目参数，不继承其他年级的值。

## 电学分支

任务涉及静电、电路、电表、欧姆定律、电功率、焦耳热或家庭电路时，补读 [physics-electricity.md](references/physics-electricity.md)。地区题源与章次以当前教材和用户范围为准。

## HTML 输出

需要离线 HTML 课件时，读 [HTML 引擎](references/html-player.md)。使用随 skill 分发的引擎和构建脚本，从课程 JSON 生成可编辑源稿与单文件 HTML；不要继承示例的科目、地区或题目授权。
